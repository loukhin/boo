## About

Literally just Ghostty with a workspace and a Bonsplit's split/tab implementation, like cmux without the thing other people love about it (browser, agent integrations, etc)

Mostly made in a day with Opus and GPT to be something I can use without having to navigate around cmux bugs (it's not bad, just not what I want), will properly rewrite and improve it myself from time to time when i feel like learning Swift.
